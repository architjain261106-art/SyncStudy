# Build Project Workflow

This workflow details the steps required to install dependencies and build the SyncStudy AI project.

## Steps

1. **Install Dependencies**:
   Run the following command to install all necessary npm packages:
   ```bash
   npm install
   ```

2. **Build the Project**:
   Run the following command to create a production build:
   ```bash
   npm run build
   ```

3. **Type Check (Optional)**:
   To verify TypeScript types:
   ```bash
   npm run typecheck
   ```
