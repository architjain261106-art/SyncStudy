# Preview Project Workflow

This workflow details the steps required to start the development server and preview the SyncStudy AI project.

## Steps

1. **Start Development Server**:
   Run the following command to start the Next.js development server:
   ```bash
   npm run dev
   ```
   The server will start on [http://localhost:9002](http://localhost:9002) by default.

2. **Verify Preview**:
   Open [http://localhost:9002](http://localhost:9002) in your browser to verify the application is running.
   You should see the "SyncStudy AI" landing page with a "Join a Classroom" card.
